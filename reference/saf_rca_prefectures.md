# Prefectures de la Republique Centrafricaine

17 prefectures de la RCA avec codes administratifs.

## Usage

``` r
saf_rca_prefectures
```

## Format

Objet sf avec colonnes : pays, iso3, prefecture, code, geometry.

## Source

Natural Earth – statAfrikR Foundation

## Examples

``` r
rca <- carte_zones('rca')
```
