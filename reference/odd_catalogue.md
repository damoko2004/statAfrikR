# Catalogue des indicateurs ODD pour les INS africains

Retourne le catalogue des indicateurs ODD implementes dans statAfrikR,
selectionnes selon leur pertinence et disponibilite pour les INS
africains (reference PARIS21, AFRISTAT, Nations Unies).

## Usage

``` r
odd_catalogue(
  objectif = NULL,
  disponibilite = NULL,
  statut = NULL,
  format = c("tibble", "flextable")
)
```

## Arguments

- objectif:

  integer ou NULL – Filtrer par numero d'ODD (1 a 17). NULL retourne
  tous les indicateurs. Defaut : NULL

- disponibilite:

  character ou NULL – Filtrer par disponibilite des donnees : `"haute"`,
  `"moyenne"` ou `"faible"`. Defaut : NULL

- statut:

  character ou NULL – Filtrer par statut d'implementation :
  `"implementee"` ou `"documentation"`. Defaut : NULL

- format:

  character – `"tibble"` ou `"flextable"`. Defaut : "tibble"

## Value

Tibble ou flextable du catalogue filtre
