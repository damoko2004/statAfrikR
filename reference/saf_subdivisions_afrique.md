# Subdivisions de niveau 1 – tous les pays africains

Prefectures, regions et provinces de 43 pays africains (744
subdivisions + 17 prefectures RCA = 761 total).

## Usage

``` r
saf_subdivisions_afrique
```

## Format

Objet sf avec colonnes : pays, iso3, subdivision, code_admin, geometry.

## Source

Natural Earth – statAfrikR Foundation

## Examples

``` r
cam <- carte_zones('subdivisions', pays = 'CMR')
```
